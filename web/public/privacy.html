Keyhole — Privacy Policy

Keyhole is a single-user, self-hosted application. It connects the operator's own Google account and re-exposes selected data to the operator's personal AI agents through scoped API keys.

Data collected

  • Google account email (admin login allowlist and connection display).
  • Google OAuth tokens for the Calendar scope, stored AES-256-GCM encrypted. Tokens never leave the server and are never shown to agents.
  • Google Calendar data (calendars and events), proxied on demand. Keyhole stores no calendar content except encrypted tokens and an audit log of API calls (method, path, status, timing — no bodies).

Data sharing

None. There are no third-party analytics, trackers, or other recipients. Agents holding a scoped key can read/write calendar data within that key's scopes until the key is revoked or expires.

Retention and deletion

Disconnecting Google deletes the stored tokens (a Google-side revocation is also attempted). Revoking an API key disables it instantly. The audit log is capped at 10,000 rows with oldest-first pruning.

Contact

Keyhole is operated by a single individual for personal use. Contact the instance operator directly.
